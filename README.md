# Código para realizar el Benchmark de la tarea de la semana 13 de Autómatas y Lenguajes Formales

Este repositorio se basa en la prueba de ambas tecnologías (Flex y Bison de C y PLY de Python) del procesamiento de 50,000 lineas de código para una simulación de una calculadora aritmética de precedencia estandar.

Para ejecutarlo se recomienda lo siguiente:
1) Tener instalado el paquete de PLY de Python.
2) Tener instalado MSYS2 y configurado la carpeta "C:\msys64\usr\bin" en variables de entorno de Path.

Una vez realizado lo anterior, solo se ejecuta el archivo "run_benchmark.py" para ver el tiempo de ejecución en tiempo real de procesamiento entre FLEX/BISON (LEX/YACC de Lenguaje C) y PLY (Python Lex-Yacc).
